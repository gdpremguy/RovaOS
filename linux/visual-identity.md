# Rova Horizon desktop

The visible theme is **Rova Horizon**: an opaque midnight/teal GTK
theme with glacier accents, built on Arc's existing widget compatibility.
Papirus application icons and Arc window decorations remain upstream assets;
this is a custom desktop treatment, not a new window manager.

- Slim status panel: Kestrel Apps, running tasks, date/time, network, sound,
  battery and Control Center.
- Bottom launch shelf: Apps, Browser, Files, Terminal and Control Center.
- Matching two-column Kestrel launcher and a branded, scrollable Control Center.
- The original Rova Horizon wallpaper, shortcuts, 125% display default and low-overhead
  non-composited rendering are retained. No transparency effects are required.

Fresh live sessions and newly generated persistent images receive these defaults.
Existing persistent users' saved preferences are not forcibly overwritten.
The GTK directory/identifier remains `Rova-Summit` for saved-theme compatibility.
The new background is generated from custom curves and gradients; editable SVG,
4K PNG and provenance notice are in `assets/wallpapers/`. Arc and Papirus retain
their own licences and credits.
