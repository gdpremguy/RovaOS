# Rova Horizon

- `rova-horizon.png`: 3840x2160 desktop wallpaper.
- `rova-horizon.svg`: editable curves and gradients.
- `HORIZON-NOTICE.txt`: provenance.

No third-party image was used as input. The artwork was created with AI-assisted
design and code and is included under the project's MIT licence.

Regenerate the PNG and SVG with Pillow installed:

```sh
python3 tools/build_horizon_wallpaper.py
```

Both Linux build paths package the wallpaper and provenance notice. Existing
users' custom wallpapers are not overwritten.
